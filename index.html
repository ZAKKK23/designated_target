plane-vtp-target-field (Voronoi Topological Perception)

The VTP agent model on the plane with a large lattice of static targets that circles around the origin and one collector target that goes after the agents, picks them up and moves so as to keep them close, ported from MATLAB to a dependency-free browser build.

Voronoi Topological Perception Delaunay-neighbor repulsion + alignment + homing Voronoi-cell speed governor circling static target lattice + 1 collector target MATLAB + JS ports no build step

The agent model

Every agent reacts to its topological neighborhood: the agents it shares an edge with in the Delaunay triangulation (equivalently, the agents whose Voronoi cells touch its own). Each step an agent's desired direction is a blend of three terms:

  • Repulsion from its nearest Delaunay neighbor, with magnitude s = transition(distance / L) that is 1 when the two are touching and fades smoothly to exactly 0 at distance L.
  • Alignment with its Delaunay neighbors, weighted by ν. Neighbors whose heading already agrees with the agent's count for more.
  • Homing toward the nearest target, with magnitude 1 − s, so repulsion takes priority when an agent is crowded.

The agent then moves along that direction at a speed of tanh(l / L), where l is the distance from the agent to the boundary of its own Voronoi cell along its direction of motion. Crowded agents (small cells) slow down; agents on the edge of the group have an unbounded cell and move at full speed.

The target field

The targets are all point targets, and every agent homes toward whichever one is currently nearest to it, except agents stuck to the collector (below):

  • Static targets form a rectangular lattice that covers the plane over [−H, H]² (by default H = 50), with a spacing in x and a spacing in y that you choose independently. H and both spacings are adjustable live.
  • The lattice goes around a circle. It moves rigidly, so its center travels on a circle centered on the origin. You choose the radius R of the circle and the speed along it (in units per time step; a negative speed goes clockwise). The lattice center is at R·(cos θ, sin θ) with θ = (speed / R) · t, so one lap takes 2πR / speed steps. R = 0 keeps the lattice still. Agents move at up to 1 unit per step, so a speed below about 1 can be followed.
  • One collector target that does not oscillate: it goes after the agents.
    • Capture. An agent that comes within the capture radius of the collector sticks to it. A stuck agent keeps feeling the target field: it homes toward a blend of the collector and its nearest lattice target, set by the field weight (0 = collector only, 1 = field only), and that homing term goes through the same VTP rules as every other agent. It stays stuck until it drifts farther than the release radius, when it lets go (and can be captured again). Stuck agents are drawn in orange.
    • Seeking. The collector moves toward the nearest agent that is not stuck yet, at up to its speed. When every agent is stuck it moves to the centroid of the group and stays there.
    • Keeping them close. The collector slows down as the centroid of its stuck agents trails behind it, with speed factor max(0, 1 − lag / keep-close). It stops when the lag reaches the keep-close distance, so it never runs off and leaves the agents it has collected behind, and it speeds up again as they catch up.

The view menu offers follow swarm, fixed (world), which keeps the camera at the origin so you can watch the lattice circle around it, and follow field, which keeps the camera on the lattice.

Two implementations, one model

  • index.html (this page, live simulation tab) is a plain JavaScript/Canvas port that runs directly in the browser. It needs no install and no external libraries, and it includes its own small Delaunay triangulation.
  • matlab/dynamics.m is the MATLAB implementation, browsable under the matlab version tab.

MATLAB version

The MATLAB implementation, in matlab/.

Requires MATLAB with the base product plus the functions it already uses for geometry (delaunayTriangulation, voronoiDiagram, polyxpoly, polyshape). Run:

cd matlab
matlab -r dynamics

...or open dynamics.m in the MATLAB editor and run it. All the target-field settings are at the top of the file:

grid_half, grid_spacing_x, grid_spacing_y % static lattice window and x/y spacing
field_speed, field_radius % speed and circle radius of the lattice's circular motion
collector_speed % top speed of the collector
capture_radius, release_radius % agents stick inside the first, let go beyond the second
keep_close % lag of the stuck group's centroid at which the collector stops
field_weight % how much stuck agents still home toward the lattice (0 = collector only)
collector_start % where the collector starts

The static lattice is plotted as grey squares, the collector as a red dot with its capture radius dotted, and the agents stuck to it in orange.

The folder holds dynamics.m and the files it depends on: Target.m and nearestOnSegment.m (target geometry and homing vectors), neighborhoods.m (Delaunay neighbors and the nearest neighbor), transition.m (the smooth cutoff function), alignTo.m (alignment), voronoiProjectToBoundary.m (distance to the Voronoi cell boundary, used for the speed governor), and voronoiForwardArea.m with poly_area.m (only needed if you switch fdim to 2).
